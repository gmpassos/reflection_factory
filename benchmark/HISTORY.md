### End to end: `bones_api`

2.12.0 (`ef2fef1`) in `bones_api` 1.22.0 (`862e069`): its
`benchmark/db_users` on SQLite (`--db=sqlite --repeat 5`), Mac17,3
(Apple M5), ops/sec (higher is better). Each 2.12.0 column is two runs
alternated with two runs of 2.11.0 on the same machine; the percentages
compare each 2.12.0 run with the 2.11.0 runs alternated with it, and the
2.11.0 range spans all of them. In the 2.12.0 builds the reflection is
regenerated (with `invoker`s).

| Operation | 2.11.0 | 2.12.0 | 2.12.0 + options |
|---|--:|--:|--:|
| `user/byId` | 24204–24572 | 26301–26364 (+7.7%) | 29046–29151 (+18–20%) |
| `user/byState (join, limit 20)` | 3151–3179 | 3487–3494 (+10.5%) | 3875–4097 (+22–30%) |
| `user/list (page of 20)` | 3379–3410 | 3680–3773 (+8–11%) | 4229–4491 (+24–33%) |

- **2.12.0:** `bones_api` unchanged. It still passes its own
  `fieldNameResolver` / `fieldValueResolver`, so it gains the `invoker` but
  keeps the `MethodInvocation` path.
- **+ options:** `ClassReflectionEntityHandler.instantiateFromMapImpl` calls
  `createInstanceFromMap(fields, valuesResolved: true, exactKeys: true)` in
  place of its resolvers. With that change, the `db_users` API tests (entity
  contents, roles and address included) still pass. Adopting it is up to
  `bones_api`.
- The reflection must be regenerated with 2.12.0: code generated by 2.11.0
  has no `invoker`, and measured about +3% (`user/list`) as is.

### 2026-10-14 — Mac17,3 (Apple M5)

- **reflection_factory:** 2.12.0 (`ef2fef1`)

- **OS:** macos (Version 26.6.2 (Build 25G83))

| Case | ns/op | ops/sec | rounds (ns/op) |
|---|--:|--:|--:|
| `account: constructor` | 450 | 2224286 | 449–450 |
| `account: constructor (valuesResolved, exactKeys)` | 385 | 2598239 | 385–385 |
| `account: fromJson` | 3035 | 329437 | 3030–3042 |

| `member: create + setters (valuesResolved, exactKeys)` | 719 | 1390113 | 719–720 |

The review fixes of #57. The `invoker` now writes the defaults of omitted
parameters in their own type context (and casts its arguments). Without a
`fieldValueResolver`, constructors are called straight from the map, so
`account: constructor` (no resolver) now takes that path too: 1694 → 450.
`fromJson` passes a resolver and is unchanged.
